How the depth works

The layers, bottom to top

  1. Base cardThe untouched card, so the full design still shows underneath.
  2. Border frameThe border cut free and lifted, with the inside edge in silver or team color.
  3. PlayerThe player cut out along the uniform, with small detail cuts for the arms, ball and cleats.
  4. Name plateThe player's name raised on top, the highest point on the card.

    How it's made

    Four steps, one card

    1. STEP 1

      Pull

      Several copies of the same base card, so every layer matches exactly.

    2. STEP 2

      Cut

      Each copy is cut to one layer: border, player, details, name.

    3. STEP 3

      Ink & stack

      Edges inked black, inner border finished, then the layers are stacked with spacers.

    4. STEP 4

      Seal

      Dropped into a 130pt one touch so the depth stays put.
